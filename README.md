# Zidaan Haneef — Artist Portfolio

A cinematic artist portfolio built with Next.js, TypeScript, Tailwind-style CSS, GSAP and Lucide.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Replace placeholder media

The project intentionally includes SVG placeholders so it runs immediately.

Replace:
- `public/hero.svg`
- `public/music/cover-01.svg`
- `public/music/cover-02.svg`
- `public/videos/*.svg`
- `public/gallery/*.svg`

with Zidaan's actual photos/videos.

For audio, add:
- `public/music/song-01.mp3`
- `public/music/song-02.mp3`

Then update `data/artist.ts` with the real links/contact information.

## Deploy

Push to GitHub and import the repository into Vercel.
